2. Copy its `index.html` into your existing website folder, replacing the old HTML file.

## What kind of work is it?

The supplied 520-word piece reads as **literary flash fiction**, written in poetic prose. It is a short story about childhood, war, displacement, and memory, shaped around an extended boat metaphor. This designed format can be described as an **illustrated short-story chapbook**. The layout preserves the supplied wording and standardizes quotation marks; design annotations and credits are separate from the story.

# Local assets

- Most `.webp` restaurant photos are optimized from the 41 original files in `../research/source-assets/`.
- `pizza-hero-cutout.png` is an AI-generated, overhead pizza concept with a true transparent alpha channel. It is not a Puglia photo or a verified menu item.
- `fonts/unifrakturmaguntia.ttf` is the locally bundled blackletter display face selected to echo the user-supplied signboard; it is an approximation, not an identified original logo font. The SIL Open Font License is in `../research/font-licenses/UnifrakturMaguntia-OFL.txt`.
- `puglia-wordmark.svg` contains vector paths for the text-only favicon.

See `../research/ASSET-ATTRIBUTION.md` before reusing anything outside this concept. Restaurant-photo rights have not been independently verified.

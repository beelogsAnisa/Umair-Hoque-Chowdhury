# Yummy Dips II — Astoria site concept

A standalone, responsive pitch-site concept for **Yummy Dips II at 25-59 Steinway St, Astoria, Queens**. The design is an expressive street-poster collage, not an arched-window hero: vertical brand rail, oversized type, hard-edge official dessert photography, interactive menu tabs, a swipeable photo strip, and a large Steinway location feature.

## Preview locally

From this directory:

```bash
python3 -m http.server 4177 --bind 0.0.0.0
```

Open `http://localhost:4177/`. No framework, external font, CDN, build step, or runtime dependency is required.

## Project files

- `index.html` — semantic structure, accessible menu tablist, location contact details, and official order/directions links.
- `styles.css` — bespoke berry / cherry-pink / misty-rose / lapis visual system, responsive layout, conspicuous hover/focus/touch states, and reduced-motion support.
- `app.js` — mobile navigation, arrow-key/Home/End menu tabs, touch-first photo strip with scroll controls, scroll reveals, and pointer-reactive poster photography.
- `assets/` — Yummy Dips logo, official Yummy Dips II Toast listing photo, and official Yummy Dips product photography.
- `research/RESEARCH-NOTES.md` — verified location distinction, source list, brand-menu caveats, contact details, image provenance, and design references.

## Research and accuracy

Yummy Dips II’s official Toast listing identifies **25-59 Steinway St, Astoria, NY 11103** and phone **(347) 572-6896**. It links to the location-specific order page. The site links there for live ordering, hours, and current availability rather than guessing a weekly schedule.

The small menu display uses selected highlights and ingredient descriptions from Yummy Dips’ broader official menu, not a claim that every item is currently offered at the Astoria location. Use the Yummy Dips II order page to confirm the live selection. A branch-specific rewards program was not verified, so this concept does not promise rewards.

## Photography and rights

The lead photo comes from Yummy Dips II’s official Toast listing. Additional food and logo assets are hosted on Yummy Dips’ official site. No generated food photography is used. Asset availability does not itself grant reuse rights; obtain permission or approved replacement assets before any public launch.

## Design and scope

The six supplied images informed the palette, bold typography, product-first photography, and playful sticker language, without copying their brands or layouts. The hero photograph is a hard-edged rectangle; it does not use an arch or window silhouette. The concept is independent, for presentation only, and has not been deployed.

# Ayat Bushwick — pitch-site concept

A bespoke, responsive one-page website concept for Ayat’s Bushwick restaurant. The creative direction uses warm paper, olive green, tomato, and saffron tones with oversized editorial type, custom inline SVG details, real Bushwick gallery imagery, and a scroll-responsive food-art feature.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 4176 --bind 0.0.0.0
```

Then open `http://localhost:4176/` in a local browser. The page has no build step, framework, external font, or runtime dependency.

## Project files

- `index.html` — semantic page structure and inline custom SVG iconography.
- `styles.css` — responsive visual system, focus/hover/touch states, and reduced-motion styling.
- `app.js` — mobile navigation, scroll reveals, pointer response, and the hero platter’s scroll-driven 3D-like tilt.
- `assets/` — optimized local images and logo artwork used by the page.
- `research/RESEARCH-NOTES.md` — source links, verified location/menu facts, and image notes.

## Important concept-art note

The hero platter is an AI-assisted concept rendering based on an Ayat food reference; it is **not an Ayat photograph**. The page labels it accordingly and recommends replacing it with restaurant-approved photography before any public launch. Other restaurant photos are downloaded from Ayat’s official Bushwick gallery for pitch/mockup use; obtain written permission or approved replacements before publishing the site.

## Scope and accuracy

This is an independent presentation concept, not an official Ayat site and not a deployed website. Location details and menu references were checked against Ayat’s official pages on October 14, 2026. The official menu says items and prices may vary by location. The displayed hours match Ayat’s Bushwick page; confirm current hours and reservation handling directly with the restaurant before launch.

The user’s supplied Mochi Matcha Bar, Pure Bite, and Enka references informed the editorial scale, food-forward composition, and warm/green palette only. No reference layout or brand identity is copied.

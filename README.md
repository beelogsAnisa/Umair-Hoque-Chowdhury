# GitHub Pages upload

Upload the contents of this folder to the root of your GitHub repository. The
root must contain `index.html`, `styles.css`, and `script.js`.

In the repository, open **Settings > Pages**, choose **Deploy from a branch**,
select `main` and `/(root)`, then save.

To use the final portrait and logo, add `professional.png` and `logo.png` beside
`index.html`. The built-in public fallbacks remain clean if those files are not
present.

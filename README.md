# GitHub Pages upload

Upload the contents of this folder to the root of your GitHub repository. The
root must contain `index.html`, `styles.css`, and `script.js`.

In the repository, open **Settings > Pages**, choose **Deploy from a branch**,
select `main` and `/(root)`, then save.

To use the final portrait and logo, add `professional.png` and `logo.png` beside
`index.html`. The built-in public fallbacks remain clean if those files are not
present.


## Bangladesh transcript image

The Education section is ready for your transcript. Save/export the image as
`bangladesh-transcript.jpg` and upload it to the repository root, in the same
folder as `index.html`, `styles.css`, and `script.js`. Use this exact lowercase
filename, including `.jpg`.

The image preview and “View transcript” link appear automatically when the file
loads. The existing 5.00 / 5.00 academic card remains visible if the image is not
uploaded or cannot load. The preview shows the whole image without cropping.
The transcript image is not included in this archive.

# Concept-image provenance

The site uses compressed WebP derivatives of photographs/product images that appeared on KAD Party Rentals’ public Wix website. The original downloads were retrieved from `https://static.wixstatic.com/media/` URLs embedded in the official homepage, product-category pages, and services/gallery page. The site assets live in `/assets/`; the original high-resolution files are not included in this project package.

Before any public deployment, ask KAD to confirm rights/permission for every image, approve the current photos, and replace any that no longer represent available inventory or recent work. Descriptive alt text in the concept identifies the visible scene/item; it is not a claim of current stock or recent event activity.
